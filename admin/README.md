# Mamak Bien-Être Admin

This folder contains the administration interface for the Mamak Bien-Être store.

The interface is built with React 19, Vite, Tailwind CSS, React Router, Axios, and Quill.

## Main areas

- Store dashboard
- Product creation and listing management
- Pending, completed, and cancelled order views
- Customer management
- Product content editing

## Local development

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run lint
```

The API and customer storefront are maintained in sibling directories. See the [repository README](../README.md) for the complete project setup.
